## WebGL Desk — hardware-accelerated hub for projects & tasks

### What gets built
A new full-screen **`/desk`** route: a 3D scene rendered with **Three.js** (already a dependency, same pattern as `src/routes/graph/embedding-map-3d.ts`). It becomes the default hub for projects and tasks, added to the memory-surface nav.

**Scene composition**
- **Desk**: a warm-neutral plane in app palette (sage-green-tinted, using resolved CSS variables; re-resolved on `theme-preference-change` so light/dark both work). Camera is a gentle top-down-oblique perspective; scroll wheel / trackpad pans the desk (smoothly eased), so it's "scrollable" both axes.
- **Project piles**: one instanced stack of paper cards per active GTD project (`projectStatus = active`, from `ProjectListItem`). Pile height/offset = open task count; subtle random jitter per sheet, project label plate in front of each pile. Click → navigate to `/memory/projects/[entityId]`. Slow "breathing" idle animation; hover lifts the top sheets.
- **Loose tasks**: open unassigned temporal events rendered as single sheets laid flat on the desk, slightly rotated, arranged in a loose grid that pans with the desk. Click → task detail (existing event deep-link). Hover raises + tilts the sheet.
- **Wall with notes**: behind the desk, a vertical wall plane. The existing knowledge-graph **nodes** (thoughts, from the same snapshot data the `/memory` graph uses) render as small pinned notes in a grid on the wall — instanced quads with canvas-baked mini-textures (title snippet only). Clicking a note selects/navigates to the thought in the graph view. Depth fog + vignette keeps the wall visually recessive.
- All cards/notes are `InstancedMesh` batches (one draw call per material) → hundreds of papers at 60fps. Per-frame work is a single eased camera/instance-attribute update; idle throttling (active 16ms / idle ~150ms) copied from the embedding map.

**Text**: hybrid — GPU draws all paper/note geometry; text labels are crisp DOM elements positioned by projecting card anchor points each frame (same technique as the embedding map's CSS2D labels), with culling by viewport so only visible labels are in the DOM.

**Interactions (v1)**
- Click pile → project detail page; click loose task → task detail; click wall note → graph view focused on that thought.
- **Drag a loose task onto a pile** → `POST /api/timeline/projects/assign` (existing endpoint), sheet animates into the pile.
- Mark-done via a small DOM context menu on task sheets (`POST /api/temporal-events/[id]/action`), reusing `timeline-item-actions.ts`.
- Reduced-motion: respect `prefers-reduced-motion` (no idle breathing, instant transitions).

### Files
- `src/routes/desk/+page.server.ts` — auth-gated load (timeline + graph snapshot data, mirroring `memory/+layout.svelte` auth).
- `src/routes/desk/+page.svelte` — Svelte wrapper: mounts/disposes the 3D handle, binds the `createTimelineData()` store, labels layer, drag affordances.
- `src/routes/desk/desk-scene.ts` — imperative Three.js factory `createDeskScene({container, projects, tasks, notes, callbacks}) → {resize, dispose, setSelected…}` (mirrors `embedding-map-3d.ts` structure, incl. dispose and pixelRatio cap).
- `src/routes/desk/desk-labels.ts` — DOM label projection/culling layer.
- `src/routes/desk/desk-theme.ts` — resolves CSS-variable palette (incl. oklch parsing via `THREE.Color`) and re-resolves on theme change.
- Nav: add "Desk" to `src/lib/components/memory-surface-nav.svelte` and make `/desk` the default landing among the project/task surfaces (nav order: Desk, Memory, Capture, Chat as fits existing layout).
- i18n strings in `messages/en.json` + `messages/de.json`.

### Testing (TDD-first, per repo rules)
Written before implementation:
- **Unit** (`*.spec.ts`): desk layout math (pile placement, loose-grid layout, wall grid, viewport culling), theme palette resolution (light + dark oklch), drag-to-assign payload mapping, label culling. Scene factory disposes all geometries/textures/renderer (leak test).
- **E2E** (headed Playwright, `test:e2e:release:headed`): `/desk` renders with ≥1 project pile and loose tasks; clicking a pile navigates to project detail; clicking a task opens task detail; drag task→pile triggers assign endpoint and pile count updates; nav link to `/desk` present.
- Run `npm run test:unit` + the desk E2E specs; no other suites should regress.

### Out of scope (v1)
No reordering piles, no editing labels on the desk, no creating tasks from the desk, no replacing/deleting the existing TimelineShell pages (they remain reachable), wall notes are read/navigate-only.
